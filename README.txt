SMS — Schedule Management System (CSD 1st Semester Prototype)
=============================================================

HOW TO RUN IN VS CODE
---------------------
1. Right-click this ZIP -> Extract All.
2. Open VS Code -> File -> Open Folder -> select "sms-csd-prototype-v2".
3. Open Terminal -> New Terminal -> switch to Command Prompt.
4. Run: npm install
5. Run: npm run dev
6. Open http://localhost:5173 in your browser.
